02 Getting Started now

Comprehensive getting-started guides for both DM and RS actuator editions

reBot B601-DM Robotic Arm
Damiao Actuator

Ideal for Damiao motor edition users to learn arm control, LeRobot, Pinocchio, and ROS 2

Target Audience
Users of B601-DM arm who want to learn robotic arm control and AI data collection
Learning Goals
Master driver setup, kinematics modeling, LeRobot data collection, and vision-guided grasping demos
Recommended Order
Quick Start → LeRobot → Pinocchio → Vision Grasping → ROS 2
1
Quick Start
Essential

Check power supply, CAN communication, driver environment, and basic movement to verify arm hardware status.
2
LeRobot Data Collection
AI Data

Use LeRobot for teleoperation, data recording, and imitation learning dataset preparation.
3
Pinocchio & Meshcat
Control Basics

Learn arm model loading, visualization, forward/inverse kinematics, and joint space control basics.
4
Vision Grasping Demo
Application

Combine robotic arm with vision algorithms to perform object grasping in real-world scenarios.
5
ROS 2 Integration
System Integration

Integrate the arm into ROS 2 for seamless combination with MoveIt, perception nodes, and system applications.
6
Web Simulator Development
Simulation Dev

Learn integrated development with Web Simulator and ROS 2/MuJoCo for synchronized virtual and physical control.
reBot B601-RS Robotic Arm
Robstride Actuator

Ideal for beginner arm setup, teleoperation, vision grasping, ROS 2 integration, and AI data collection

Target Audience
First-time reBot Arm users who want to quickly achieve real arm control
Learning Goals
From hardware power-on to LeRobot teleoperation, vision grasping, and ROS 2 integration
Recommended Order
Quick Start → LeRobot → Pinocchio → Vision Grasping → ROS 2
1
Quick Start
Essential

Complete unboxing, wiring, power supply, driver check, and basic motion tests to ensure normal operation.
2
LeRobot Teleop & Data Collection
Data Collection

Learn teleoperation data collection via leader-follower arms for imitation learning and embodied AI tasks.
3
Pinocchio Kinematics Visualization
Advanced Control

Understand arm kinematics models, joints, coordinate frames, and forward/inverse kinematics for control algorithms.
4
Vision Grasping Demo
Application

Combine camera perception, target recognition, and pose generation to perform real object grasping.
5
ROS 2 Integration
System Integration

Integrate arm into the ROS 2 ecosystem for seamless combination with perception, planning, and simulation.
6
Web Simulator Development
Simulation Dev

Learn integrated development with Web Simulator and ROS 2/MuJoCo for synchronized virtual and physical control.
7
Isaac Sim Integration
Simulation

Integrate the arm into Isaac Sim for advanced simulation and virtual-to-real synchronization.
8
MIT Position Control
Advanced Control

Get started with MIT position control on reBot Arm B601-RS to master fundamental control algorithms.
